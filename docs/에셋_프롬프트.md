## 0-1. 규격 — 모델이 거부하지 않게

`gpt-image-2.5`는 **가로·세로가 16의 배수**이고 **총 65만 화소 이상**이어야 한다.
아래 본문에 적힌 512×512(26만)·256×768(19만)·128×128은 전부 미달이다.
**크게 뽑고 Pillow로 줄인다.**

| 쓰임 | 생성 | 최종(구울 때) |
|---|---|---|
| 머리·아이콘·이펙트·등급틀 | **1024×1024** | 56×56 · 128×128 |
| 몸통·팔다리·망토 | **1024×1536** | 74×110 |
| 무기 (1:3) | **512×1536** | 26×78 |
| 배경 | **1024×1024** | 그대로 |

**투명 배경은 프롬프트 글자가 아니라 `background: "transparent"` 파라미터로 받는다.**
글자만으로는 진짜 알파가 안 나온다. (본문 STYLE의
`isolated on pure transparent background`는 구도를 잡는 용도로만 남긴다)

## 0-2. 가장 중요한 것 — 한 줄을 고정한다

**조각마다 프롬프트를 새로 쓰면 그림체가 전부 따로 논다.** 아래 한 줄을
**모든 프롬프트 앞에 똑같이** 붙이고, 뒤에 그 조각만 바꾼다.

```
STYLE (고정, 절대 바꾸지 말 것):
korean wuxia murim, flat vector illustration, bold clean outlines,
limited palette of ink black #0f0d0b, bone white #f1e8d6, old gold #d4a64a,
blood red #a3242a, muted jade #3f7d5a, matte colors with no gradients,
no text, no watermark, no signature, centered, isolated on pure transparent
background, orthographic top-down-friendly silhouette, game asset sheet
```

**세 가지는 매번 붙인다.**
- `isolated on pure transparent background` — 안 붙이면 잘라내는 데 더 오래 걸린다
- `no text` — 생성 모델은 한자·영문을 멋대로 집어넣는다
- `no gradients` — 우리 화면은 평면이라 그라데이션이 섞이면 혼자 뜬다

**뽑는 방식: 한 장씩 고르지 말고 한 번에 8~12장 뽑아 그중 1~2장만 남긴다.**
(AI-ARCHIVE 「물량 생성 → 선별」 — 한 장씩 고르면 평균치에 수렴한다)

## 4. 뽑은 뒤

1. 알파 섬으로 자동 분리 — 조각 사이가 투명하면 손으로 자를 일이 없다
   (Blade Idle 아틀라스에서 421조각을 그렇게 뽑았다)
2. 무기는 **주축을 재서 자동으로 세운다** — 기울어진 채로는 손에 못 쥔다
3. `art/` 아래 이름을 키에 맞춰 둔다 — `head-band.png` · `body-dark.png` ·
   `wp-sword.png`. 코드(`js/art.js`)가 그 이름으로 찾는다
4. 한 장이라도 빠지면 **전부 벡터로 떨어진다**. 묶음 단위로 완성해서 넣는다
