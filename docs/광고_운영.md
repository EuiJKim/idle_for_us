# 광고와 광고 제거 — 운영 안내

## 지금은 흉내만 낸다

`js/ads.js`가 5초짜리 **가짜 광고 화면**을 띄운다. 친구끼리 하는
GitHub Pages 게임이라 실제 광고망을 못 붙인다 — AdSense는 도메인·승인이
필요하고, '보면 보상' 방식은 AdSense 정책 위반이다.

나중에 진짜로 붙일 때 **`showAd` 하나만** 갈아 끼우면 된다.
부르는 쪽(`missions.js`, `main.js`)은 '광고 한 편 보여 주고 끝나면 알려줘'만 안다.

```js
export function showAd(adFree = false) -> Promise<boolean>
```

`true`면 끝까지 봤다는 뜻이고, 그때만 보상을 준다.
**광고를 지운 사람에게는 아예 안 띄우고 바로 `true`다** — 그게 산 것이다.

## 광고가 막는 것 / 안 막는 것

**원래 공짜이던 걸 광고 뒤로 옮기지 않았다.** 있던 걸 빼앗으면 개악이다.

| | 광고 없이 | 광고 보면 |
|---|---|---|
| 기연 | 하루 3회 (그대로) | **+1회 더** |
| 방치 보상 | 그대로 | **2배** |

검사(`tests/check.mjs` 25절)가 "공짜 기연 횟수는 그대로다"를 매번 본다.

## 광고 제거 — 입금 → 운영자가 켜기

### 플레이어가 하는 일

의뢰 탭 → **광고 제거** 카드 → 계좌로 입금 → **신청 번호**를 운영자에게 보냄
(카드의 〈신청 번호 복사〉를 누르면 복사된다).

### 운영자가 하는 일

Firebase 콘솔 → Firestore Database → 데이터 →
컬렉션 `entitlements` 에 **문서 ID를 그 신청 번호로** 만들고:

```
noAds  (boolean)  true
```

끝이다. 그 사람이 다음에 접속하면 바로 켜진다.

### 왜 players/{uid}에 안 두나

**거기는 본인이 자유롭게 쓴다.** 프로필을 올려야 하니 그래야 한다.
광고 제거를 거기 두면 **누구나 스스로 켤 수 있다.**

`entitlements/{uid}`는 규칙에 **읽기만** 적어 뒀다. 쓰기 규칙이 아예 없으므로
클라이언트는 못 쓰고 콘솔(운영자)만 쓸 수 있다. 검사가 이것도 매번 본다.

### 켜 주기만 하고 뺏지는 않는다

서버에 `noAds: true`가 있으면 켜고, 없다고 해서 끄지는 않는다.
입금했는데 운영자가 아직 안 켠 사람이 쓰던 걸 잃으면 안 된다.
(세이브를 고쳐 켜는 건 막을 수 없다 — 친구끼리 하는 게임이고, 어차피
세이브는 통째로 고칠 수 있다.)

## 계좌 정보는 저장소에 안 둔다

공개 저장소다. Firestore `config/shop` 문서에 둔다:

```
bank   (string)  '○○은행 000-0000-0000 홍길동'
price  (string)  '5,000원'
note   (string)  '입금자명을 신청 번호로 해 주시면 빨라요'  (없어도 됨)
```

콘솔에서 고치면 **배포 없이** 바로 바뀐다. 등록 전에는 카드에
"계좌 정보가 아직 등록되지 않았어요"가 뜬다.

## 보너스 크기

공격력 ×1.2 · 체력 ×1.2. 문파 보너스가 ×1.3~2.5이므로 **그보다 작게** 뒀다 —
돈이 실력을 덮으면 같이 하는 재미가 없다. 검사가 이 관계도 지킨다.
