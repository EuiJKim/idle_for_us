## 2판 — 온라인·상태 안정 (이틀)

- 연결이 끊긴 채 판이 끝나면 그 판 피해가 통째로 사라진다 → `s.wraid.pending[id]`에 남겨 다음 연결 때 보낸다(3분 안이면 늦은 한 몫).
- 순위를 리스너 복사본으로 셈 → 보상 트랜잭션 안에서 `damage`로 다시 센다.
- 마왕이 다음 번호로 넘어간 뒤 올린 늦은 한 몫은 재시작 전까지 안 보인다 → 그 문서를 한 번 더 읽어 `noteDone`.
- 함께 사냥: 나갈 때 전송이 실패하면 `pend`가 다음 방 두목에 들어간다 → leave에서 pend/miss/okAt 초기화, 기준+번호로 키.
- 프로필 규칙 거부 한 번에 온라인 전체가 꺼진다(v416 때 겪음) → 거부를 프로필 기능으로만 좁히고 상태 알약에 까닭 표시.
- 재접속 뒤 함께 사냥 존재 정보(이름·모습)가 비어 "문파원"으로만 보인다 → `.info/connected`에서 presence 다시 보냄.
- 다시 합류가 이미 죽은 마왕 캐시로 시작해 바로 끝난다 → 시작 전 문서 한 번 새로 읽기.
- `ensureWraid`가 문서가 지워진 번호를 만나면 영원히 "깨우지 못했어요" → 그 번호 문서를 그대로 만든다.
- 보상 서버 표시 뒤 지급 중 오류면 보상이 사라진다 → 지급 try/catch · 즉시 저장 · 실패 시 다시 받기 길.
- `enterMap`이 던전을 조용히 버린다(체력 복원·입장 횟수·칠대성 미전송 피해 유실) → inst가 있으면 leaveInst 먼저.
- 기기 시계가 미래였던 세이브는 방치 보상이 영원히 0 → migrate에서 clockMax/lastSeen을 지금+1일로 클램프.
- 세이브 검증 없음: `rar: 9`면 캐릭터가 안 열리고, 애완동물 lv 없으면 NaN으로 몹이 안 죽는다 → migrate에서 범위 클램프.
- 회랑 주차가 던전 중에 바뀌면 새 주가 옛 층에서 시작·층 보상 누락 → inst에 주 키를 저장해 다르면 1층으로.
- 오늘의 강호 '일일 던전' 과제가 입장 순간에 세어진다 → 완료(kills>0)·소탕 때만.
- 문파 가입이 캐릭터별 `guildId`에 걸려 한 계정이 두 문파 명단에 동시에 든다 → 가입은 계정 단위, 가입 때 이전 문파 탈퇴.

## 3판 — UI/UX 다듬기 (이틀)

높음
- 아래 창 단추 7개가 390px 한 줄에 억지로 들어가 「동료」가 잘린다 → 글자 줄이지 말고 2글자 통일(무림 em 제거) 또는 동료·무림을 더보기로.
- 성장 지도 「다음: …」이 2열에서 말줄임 → 전폭 1열 또는 2줄 허용.
- 강화 타일 아래 "100% · 1,400 · 현철 72"에 라벨 없음 → "성공 100% · 은자 1,400 · 현철 72(가진 69)".
- 「승급」이라는 말이 장비 쪽에 남아 있는데 승급 기능은 v173에 없앴다(canPromote 항상 false) → 문구·promoteCost·promoteStones 제거.
- 던전 › 십이지가 빈 12칸 + "10층"만 → "무한의 탑 10층마다 뽑기권 3장 · 지금 n층" + 탑 가기.

중간
- 이름 충돌: 칠대고수(고수) ↔ 칠대성(마왕), 십이지왕(지도) ↔ 십이지(던전 뽑기) → 「일곱 고수」, 「신수 뽑기」.
- 오프라인 빈 상태가 창마다 다름(문파만 다시 연결 단추) → 공용 오프라인 카드 하나.
- 무공 설명 "범위 +-35%"(부호) · 숨·사거리·범위가 한 문장 → 부호 분기, 2열 미니 표.
- 소환 "×1 (100)" 단위 없음 · "천장" → "포획 조각 100", "보장까지 0/300".
- HUD 사냥터 칩이 "두목 …"에서 잘림 → 390px용 짧은 문구.
- 조사 "을(를)/(으)로" 10곳+ → 받침 판별 유틸 하나.
- 가방: 「골라 팔기」 두 번 · 자동 정리(토글)와 +10칸(구매)이 같은 모양 · 1,000 단위 없음.
- 창고 「꺼내기」가 두 줄로 꺾임 → nowrap.
- 단련(영구 강화)이 재료 탭 안에 숨어 있음 → 강화 탭 또는 능력치로.
- 칠대성 설명 7항목이 기본 펼침 → 기본 접고 한 줄 요약(Lv.120 · 온라인 · 탄 피해 치기 · 순위 보상).

낮음
- 일일 던전 규칙 글·「모두 소탕」 뜻 설명 없음. "(컴퓨터는 Q)"가 폰에 노출. "차림" 용어.

## 4판 — 시스템 설계 (사흘, 밸런스는 시뮬로 확인)

- **5차 관문 직업별 격차**: 환마·독마 Lv160 맹주, 검사 Lv175 천마, 권마 Lv190 화무기, 소마 Lv200 마귀(화무기 먼저). 같은 Lv130 관문인데 40레벨 차. → 공통 관문(각자 세력 맹주 또는 Lv160대)으로 통일, 천마·화무기·마귀는 각성 보상으로.
- **5차 비용 5천만**: 사냥 벌이 기준 1차 0.01h · 2차 0.05h · 3차 1.2h · 4차 7h · 5차 45h. → 1,500~2,000만(4차 ×8~9 패턴).
- **끝없는 모드 보상 곡선**: 회랑 체력 ×1.07^n(복리) vs 은자 +5%/층(선형) → 60층에서 체력 ×58 / 보상 ×4. 요일 던전 31단계부터 같은 구조. → 보상도 완만한 지수(1.04^n) 또는 체력을 선형으로.
- **솔로가 못 닿는 영구 전투력**: 문파 Lv20 공격력 +38%(탑 120층 전체 덤의 2/3) · 관문 +24% · 대성신장 세트 · 온라인 칭호. → 문파 덤 상한 +20% 또는 솔로 대체 경로(각성 고수 보상에 대성신장 조각).
- **같은 말 셋**: '각성'(각성 고수 / 무공 각성·변형 / awaken형 버프 무공), '각인'(등급 각인 / 기운 각인·단). → 무공 변형은 '변초', 등급 올리기는 '승격'.
- 등급 이름 통일: 레전드→전설, GRADES(일반·고급·희귀·영웅·전설·지왕)는 색만.
- 신수 입수 경로 셋(탑 뽑기권·세력 상점·일반 소환 0.1%)과 주석 모순 → 소환 풀에서 빼거나 설명을 맞춘다.
- 세트 장비(Lv99 전반 왕)와 강화석(Lv124+ 후반 왕) 간격 → 전반 왕도 소량 떨구게.
- 죽은 가지 정리: ENHANCE_LV_CAP 분기, dailyOpen/dailyNeed, stepUpper, TIER_COUNT, CRAFT_SLOTS, stepGrade, MOUNT_DROP_MOB, STEPK, WRAID_PER_DAY, s.dgn.keys, promote 일체, heroDied 무의미 줄.
- 무공 점수가 Lv5부터 쌓이는데 1차(Lv10)까지 쓸 곳 없음 → SKILL_PT_FROM = TIERS[1].level.
- 이름 중복(애완 손오공·백호·황룡 ↔ 마왕·십이지 탈것, 탈것 천마 ↔ 고수 천마 ↔ 5차 천마, 애완 혼 ↔ 천마혼) → 영수·신마 접두어.
- 탈것 도감 "스물넷 모두"가 실제 30종 → 목표 30 또는 극 신수 제외 명시.
- ★ 운영자 칭호 `yoon: '윤석열의 가호'`(공격력 ×3, 〈Yoon Again〉) — 실존 정치인 이름 · 값도 다른 칭호의 10배 밖. → 제거 권고(마귀에 실명을 안 넣기로 한 원칙과 같은 이유).
- UI에 설명이 없는 수치: 레벨 차 벌점·패기, 처치 포화(분당 800), 방치 효율 구간(2h/6h/14h), 쓰러짐 경험치 -5% → 각 자리에 한 줄.
