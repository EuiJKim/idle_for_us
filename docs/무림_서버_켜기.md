# 무림(문파·서열·채팅) — 해결됨 (2026-10-21)

## 결론

규칙을 게시한 뒤 **11가지를 전부 확인했다. 다 통과한다.**

| 되어야 하는 것 | | 막아야 하는 것 | |
|---|---|---|---|
| 내 기록 쓰기·읽기 | OK | 남의 프로필 쓰기 | 막힘 |
| 서열 목록 읽기 | OK | 별호 13자 | 막힘 |
| 문파 만들기·읽기 | OK | 남을 문주로 세우기 | 막힘 |
| 채팅 보내기·읽기 | OK | 문파 이름 17자 | 막힘 |
| 창고 넣기 | OK | 남 이름으로 채팅 | 막힘 |
| 토벌 기록 | OK | 등급 9 넣기 | 막힘 |
| 문파 나가기 | OK | | |

게임에서도 확인했다 — 서열에 실제 인물이 뜨고, 문파 만들기·가입 화면이
열리고, 콘솔 오류 0건.

> **점검용 찌꺼기 하나.** `guilds/ZZTEST`에 빈 문파 문서가 남아 있다
> (점검하느라 만들고 나왔다). 규칙상 문파 문서는 지울 수 없게 해 뒀으니,
> 거슬리면 Firebase 콘솔에서 직접 지우면 된다. 게임에는 안 보인다 —
> 코드를 아는 사람만 들어갈 수 있다.

---


## 확정된 원인 (2026-10-21)

콘솔에 올라가 있던 규칙은 이것이었다 — **전부 거부**다.

```
match /{document=**} { allow read, write: if false; }
```

Firebase가 '프로덕션 모드'로 프로젝트를 만들 때 넣는 기본값이고,
한 번도 바꾼 적이 없었다. 코드 잘못이 아니다.

## 재 본 결과

브라우저에서 직접 재 봤다.

```
프로젝트  idle-69772
익명 로그인  성공  (isAnon: true)
players/{내uid} 읽기  permission-denied
players/{내uid} 쓰기  permission-denied
```

**로그인은 되는데 읽기·쓰기가 전부 막혔다.** 저장소의 `firestore.rules`는
로그인만 하면 읽게 되어 있으므로, 그 규칙이 **Firebase에 안 올라가 있다**는 뜻이다
(규칙을 한 번도 게시 안 했거나, 테스트 모드 기간이 끝나 기본값인 전부 거부로 돌아간 것).

코드와 규칙은 대조해 봤고 **전부 맞는다**:

| 규칙이 요구하는 것 | 코드가 보내는 것 |
|---|---|
| 별호 문자열 12자 이하 | 입력칸 2~10자 |
| 문파 이름 16자 이하 | `maxlength: 16` |
| 문파 최대 10명 | `GUILD_MAX = 10` |
| 채팅 200자 이하 | `maxlength: 200` |
| 창고 `kind`가 equip·acc, `grade`는 정수 0~5 | 그대로 |
| 들어갈 때 `memberIds`·`members`만 바뀌고 한 명 늘어남 | 그대로 |

**그러니 규칙만 올리면 바로 열린다.** 코드는 손댈 게 없다.

## 켠 방법 (기록)

1. https://console.firebase.google.com/project/idle-69772/firestore/rules 를 연다
2. 저장소의 `firestore.rules` 내용을 **통째로 붙여넣는다**
3. **게시**를 누른다
4. 게임을 새로고침한다 — 무림 탭이 열린다

> 확인하는 법: 개발자 도구 콘솔에 `[net] 서버 권한이 막혀 있어 끊습니다`가
> 더 이상 안 나오면 된 것이다. 화면 오른쪽 위도 `온라인`으로 바뀐다.

## 이 규칙이 허용하는 것 / 못 막는 것

친구끼리 하는 게임이라 느슨하게 뒀다. 알고 쓰는 게 낫다.

- **서열 숫자는 믿을 게 못 된다.** 전투력·관문은 각자 기기에서 계산해
  올린다. 마음먹으면 아무 숫자나 쓸 수 있다. 서버가 검산하지 않는 한
  막을 방법이 없고, 그러려면 Cloud Functions가 필요하다.
- **문파원은 문파 문서를 자유롭게 고칠 수 있다.** 남을 내보내거나
  문주를 바꾸는 것도 된다. 열 명짜리 친구 모임이라 그냥 뒀다.
- 남의 프로필은 **읽기만** 된다. 쓰기는 본인 것만.
- 채팅·창고는 **그 문파원만** 읽고 쓴다.

## 왜 내가 못 올리나

`firebase` CLI가 이 컴퓨터에 없고, 깔아도 `firebase login`은 브라우저로
직접 로그인해야 한다. 콘솔 접근 권한이 있는 사람만 할 수 있는 일이다.

## 익명 로그인은 이미 켜져 있다

`isAnon: true`로 로그인에 성공했으므로 Authentication 쪽은 건드릴 게 없다.
(만약 나중에 꺼지면 로그인 자체가 실패해서 `offline`으로 뜬다 —
지금처럼 `permission-denied`가 아니라.)
