# 강해지는 요소 (v109 기준)

> 공격력 = (5 + 레벨×0.5 + 힘×0.8 + **장비 공격력**) × (1 + **장비 공격%** + 문파 버프)
> 체력 = 60 + 레벨×5 + 체력×5 + **장비 체력**
> 레벨 60·지역 10 상급 장비 기준: **공격력의 86%, 체력의 88%가 장비**에서 나온다.

## 1. 장비 — 가장 큰 몫

| 칸 | 올려 주는 것 |
| --- | --- |
| 무기 | 공격력 |
| 옷 | 최대 체력 |
| 모자 | 최대 체력 · 방어 |
| 장신구 | 치명 확률 · 공격력 % |

- **조합 사다리 54칸** — 지역 27개(보통 15 + 십이지왕 12) × 하급·상급
  - 하급 = 앞 지역 장비 + 이 지역 재료 + 은자
  - 상급 = 이 지역 하급 + 재료 ×1.5 + 두목 증표 + 은자
  - 칸이 오를수록 아이템 레벨과 배수(×1.12^½)가 같이 올라 늘 '하급 < 상급 < 다음 하급'
  - 끝: 상급 무형검(제1왕 검왕)
- **강화 +1 ~ +10** — 은자 + 그 장비 지역 재료(4 + 3×단계)
  - 한 단계에 기본 수치 +12% (+10이면 2.2배)
  - 성공률 100% → 40%, 실패해도 깨지지 않음
  - 위 장비로 조합하면 강화의 절반을 이어받음
- **두목 드랍** — 두목 12%(십이지왕 30%)로 그 지역 하급 장비를 통째로
- 재료: 졸개 40%로 1개 · 두목 12개 + 증표 1개 (증표는 두목 구역에서만)

## 2. 레벨 — 작은 몫

- 레벨당 공격력 +0.5, 체력 +5, 스탯 점수 3
- 레벨이 높을수록 높은 구역에 들어갈 수 있다(= 더 좋은 재료·장비)

## 3. 스탯

| 스탯 | 효과 (1점당) |
| --- | --- |
| 힘 | 공격력 +0.8 |
| 민첩 | 치명 +0.4%p · 공격 속도 +1% |
| 체력 | 최대 체력 +5 · 방어 +0.2 |
| 내공 | 스킬 피해 +2% · 체력 회복 |

- **무공 비급** — 은자로 스탯 점수 +1 (5,000부터 권마다 ×1.18)
- 캐릭터마다 기본 스탯과 결이 다르다:
  검사 두목 피해 +30% · 권마 공격 속도 +25% · 환마 맞은 적 둔화 · 독마 중독(피해의 60%) · 극악소마 치명 +8%p

## 4. 전직 (레벨 15 · 40 · 75, 은자 200 · 5,000 · 120,000)

| 차수 | 배우는 스킬 | 세기 | 대가 |
| --- | --- | --- | --- |
| 1차 | 일격기 | 한 적에게 공격력 ×3.2 · 숨 4초 | 없음 |
| 2차 | 전체기 | 둘레 모두에게 ×2.4 · 숨 6초 | 최대 체력 10% |
| 3차 | 비기 | 넓은 자리에 ×5.5 · 숨 14초 | 최대 체력 22% |

- 스킬 세기는 공격력(= 장비)과 내공을 따라간다

## 5. 문파

- 문파 레벨마다 전원 공격력 +2% (최대 Lv.20 → +38%)
- 출석(+20)·은자 기부(+10, 하루 세 번)로 문파 레벨이 오른다
- 문파 창고로 조합 재료를 나눠 쓴다

## 강함은 아니지만 버티게 해 주는 것

- 물약(최대 체력 35%, 체력 45% 아래면 자동) · 자연 회복 · 마을에서 쉬기
