# 강해지는 요소 (v112 기준)

> 공격력 = (5 + 레벨×3 + 힘×3 + **장비 공격력**) × (1 + **장비 공격%** + 힘×0.3% + 문파 버프)
> 체력 = (60 + 레벨×25 + 체력×20 + **장비 체력**) × (1 + 체력×0.3%)
> 장비를 다 벗으면 줄어드는 만큼(= 장비 몫): Lv60 유니크 +6 차림이면 **공격력 70% · 체력 60%**.
> 초반엔 레벨·스탯 몫이 크고, 장비를 키울수록(등급·강화·돌파) 장비 몫이 커진다(시뮬 24시간 공격 83%).

## 1. 장비 — 가장 큰 몫

| 칸 | 올려 주는 것 |
| --- | --- |
| 무기 | 공격력 |
| 옷 | 최대 체력 |
| 모자 | 최대 체력 · 방어 |
| 장신구 | 치명 확률 · 공격력 % |
| 가락지 | 공격력 % · 치명 피해 + **두목마다 다른 덤 능력** — 두목만 떨군다(죽림 3% … 천외천 10% · 왕 12~17%) · 강화가 어렵다(성공률 절반·은자 ×3·돌파 없음) |
| 귀걸이 | 최대 체력 % · 스킬 피해 + 두목마다 다른 덤 능력 — 가락지와 같다 |

- 가락지·귀걸이는 **두목마다 종류(이름·덤 능력)가 다르다**: 죽림 청죽환·죽엽 귀걸이 … 천외천 천외 지환·별빛 귀걸이 … 검왕 무형 검환·검왕 귀걸이.
  높은 두목 것일수록 기본 수치·덤 능력이 크다(죽림 레어 청죽환 공격력 +2% 남짓 → 천외천 유니크 천외 지환 +45%).

- **조합 54칸** — 지역 27개(보통 15 + 십이지왕 12) × 하급·상급. v120부터 **재료만 있으면 어느 칸이든** 바로 만든다
  - 하급 = 이 지역 재료 + 은자 · 상급 = 재료 ×1.5 + 두목 증표 + 은자
  - 같은 칸의 더 낮은 조합 장비(몇 칸 아래든)를 넣으면 재료가 그대로, 안 넣으면 재료 1.5배
  - 넣는 장비의 **등급·스킬 옵션은 이어받는다**(더 높게 뜨면 그 등급으로 새로)
- **등급** — 같은 장비라도 넷. 기본 수치 배수와 스킬 옵션 수가 다르다.

| 등급 | 기본 수치 | 스킬 옵션 | 얻는 길 |
| --- | --- | --- | --- |
| 레어 | ×1 | 1개 | 조합 82% |
| 유니크 | ×1.25 | 1개(더 셈) | 조합 15% · 두목 38% · 왕 40% |
| 전설 | ×1.55 | 2개(더 셈) | 조합 3% · 두목 14% · 왕 30% |
| 신화 | ×2.0 | 2개(가장 셈) + **특수 효과** | 두목 3% · 왕 10% · 승급 |

- **승급**(장비를 눌러서) — 그 지역 재료 30×n · 증표 2×n · 은자로 한 등급 위(확정), 옵션은 새로
- **강화 +1 ~ +10** — 은자 + 그 장비 지역 재료(4 + 3×단계), 한 단계 +12%, 성공률 100%→40%
- **돌파 +11 ~ +15** — 강화에 더해 두목 증표(1~5개), 한 단계 +20%, 성공률 30%→12% (+15면 기본 수치 ×3.2)
- 실패해도 깨지지 않음 · 위 장비로 조합하면 강화(+10까지 몫)의 절반을 이어받음
- **두목 드랍** — 두목 12%(십이지왕 30%)로 그 지역 하급 장비를 등급을 굴려서 통째로

## 2. 장비의 스킬 옵션 — 스킬을 키운다

| 옵션 | 붙는 스킬 | 레어 / 유니크 / 전설 / 신화 |
| --- | --- | --- |
| 피해 | 1·2·3차 | +12% / +22% / +35% / +60% |
| 범위 | 2·3차 | +10% / +18% / +28% / +45% |
| 범위(주변 적도 맞는다) | 1차 | 주변 적에게 25% / 40% / 60% / 100% |
| 숨(재사용) | 1·2·3차 | -8% / -12% / -18% / -30% |
| 체력 소모 | 2·3차 | -15% / -25% / -40% / -60% |
| 치명 | 1·2·3차 | +6%p / +10%p / +16%p / +25%p |

**신화 특수 효과**(하나): 30% 확률로 한 번 더 터진다 · 체력을 쓰지 않는다(2·3차) · 적을 쓰러뜨리면 숨이 바로 돈다

**십이지왕 신화 고유 효과** — 그 왕 지역 장비가 신화면 보통 특수 효과 대신 왕의 것

| 왕 | 고유 효과 |
| --- | --- |
| 제12왕 권왕 | 유혼절명권 — 평타 세 번째마다 피해 ×3 |
| 제11왕 철왕 | 기관 갑주 — 받은 피해의 40%를 되돌린다 |
| 제10왕 음왕 | 귀혼음 — 스킬에 맞은 적이 1.5초 멎는다 |
| 제9왕 혈왕 | 혈해 — 준 피해의 4%만큼 체력을 빨아들인다 |
| 제8왕 목왕 | 목형천혼술 — 체력 30% 아래로 떨어지면 절반을 되찾는다(60초에 한 번) |
| 제7왕 화왕 | 천녀야우장 — 치명타가 둘레 적에게 60% 번진다 |
| 제6왕 암왕 | 암천야신공 — 체력 40% 아래 적에게 피해 +60% |
| 제5왕 환왕 | 환영 — 25% 확률로 공격을 흘린다 |
| 제4왕 살왕 | 명부살법 — 적을 쓰러뜨리면 4초간 공격 속도 +50% |
| 제3왕 투왕 | 투신 — 두목에게 주는 피해 +50% |
| 제2왕 도왕 | 일월암혈도법 — 치명 피해 +80% |
| 제1왕 검왕 | 무형신검 — 평타가 둘레 모든 적을 벤다(70%) · 스킬 피해 +30% |

**애완동물 +N** — 가락지·귀걸이(유니크 이상)에 35%로 붙는다: 유니크 +1 · 전설 +2 · 신화 +3

## 3. 스킬 레벨

- 레벨 15부터 레벨이 오를 때마다 **스킬 점수 1** — 스킬 Lv.n → n+1에 점수 n, 최대 Lv.10
- 한 레벨에 피해 +7% · 숨 -2%
- Lv.5: 범위 +15%(1차는 주변 적 20%) · Lv.10: 범위 +15% 더(1차 20% 더) · 치명 +10%p

## 4. 레벨 · 스탯

- 레벨당 공격력 +3, 체력 +25, 스탯 점수 3, (15부터) 스킬 점수 1
- 레벨이 높을수록 높은 구역에 들어간다(= 더 좋은 재료·장비)

| 스탯 | 효과 (1점당) |
| --- | --- |
| 힘 | 공격력 +3 · 공격력 +0.3% |
| 민첩 | 치명 +0.4%p · 공격 속도 +1% |
| 체력 | 최대 체력 +20 · 최대 체력 +0.3% · 방어 +0.2 |
| 내공 | 스킬 피해 +0.7% · 체력 회복 (v118: 3%에서 내렸다 — 내공 많은 환마·독마의 스킬이 2.5배 셌다) |

- **무공 비급** — 은자로 스탯 점수 +1 (5,000부터 권마다 ×1.18)
- 캐릭터 결(평타 특성)과 무공은 아래 '다섯 마존'

## 5. 다섯 마존 — 전직(레벨 15 · 40 · 75)과 무공 (v118)

평타 특성과 무공 셋이 직업마다 다르다. 같은 레벨·장비로 재면 들판 처치 속도와 두목 딜이 평균의 85~120% 안
(예전엔 내공 몫 때문에 후반 두목 딜이 권마 9배 · 독마 23배로 2.5배 벌어져 있었다).

| 직업 (3차 이름) | 평타 특성 | 1차 | 2차 | 3차 |
| --- | --- | --- | --- | --- |
| 검사 (일화검존) | 이동 +15% · 네 번째 평타마다 꽃잎 검기 둘레 220% · 두목 +10% | 일화참 ×3.5 (두목 1.25배, 멀리서도) | 낙화유수 ×1.6 두 번 | 만화귀일 ×5.0 + 8초 공격 속도 +40% |

| 환마 (섭혼마존) | 멀리서 · 맞은 적 둔화·받는 피해 +15% · 피해 2% 흡수 | 섭혼술 ×4.8 + 2.5초 멎음·6초 취약 +30% | 혈루미혼 ×2.3 + 2초 멎음 | 천외혈마공 ×5.6 + 피해 5% 흡수·취약 +20% |

스킬 점수(레벨 15부터 레벨마다 1점)를 무공과 나눠 쓴다. 공용은 1점씩, 독문 심법은 무공처럼 n→n+1에 n점. 모두 최대 10레벨.

## 6. 애완동물 (동료 창)

- **두목만** 떨군다 — 초반 두목은 **아주 낮게, 아래 순위만**, 높은 두목일수록 자주·위 순위까지
  (죽림 0.08% · 천외천 0.9% · 권왕 2.2% … 검왕 3.8%). 등급(레어~신화)도 굴린다.
- 데려가면 곁에서 **무인 공격력에 비례해** 적을 친다 + 무인에게 버프. 위 순위일수록 둘 다 크다.

- 무인 경험치의 절반을 받아 자란다(최대 Lv.30) — 레벨마다 버프 +5%, 한 대 +1.2%p · 등급만큼 곱
- **한 번에 한 마리**: 키우던 것을 **놓아줘야**(되돌릴 수 없음) 우리에서 기다리는 새 것을 데려간다
- 가락지·귀걸이의 '애완동물 +N'만큼 **여러 마리를 함께** 키운다
