# Blade Idle 설계 원리 — 공략글에서 읽어낸 것 (2026-10-17)

> 출처: 네이버 게임 라운지 블루데이님 공략 2편
> ① "게임의 전체적인 육성 흐름" ② "온라인/오프라인 비교와 등반 타이밍"
> APK 수치 분석([BladeIdle_분석.md](BladeIdle_분석.md), [BladeIdle_진행구조.md](BladeIdle_진행구조.md))이
> "어떻게 만들었나"였다면, 이 문서는 **"플레이어가 왜 계속하나"**다.

## 1. 해금이 스테이지에 못 박혀 있고, 어느 지점에서 끝난다 ★

```
 2-25  특별 무료 패키지(2만 다이아)
 3-20  펫 던전
 8-20  문양 던전
 8-25  길드
 8-50  PvP · 도플갱어
11-25  매직 장신구 상자 드랍
13-50  레어 장신구 상자
15-50  레이드 1단계            ← 매일 티켓 2장 구매 가능
17-50  영웅 장신구 상자
20-50  레이드 2단계            ← 갓 피규어
21-25  1등급 영웅 장신구 상자  ← 갓 장신구 선택상자 0.5% 드랍 시작
21-50  전설 장신구 상자
25-25  신화 장신구 상자
25-50  레이드 3단계
───── 이후 골드·경험치·다이아 소폭 상승 외에 새 보상 없음 ─────
```

**해금은 전부 챕터의 20·25·50번 스테이지에 몰려 있다.**
DB에서 찾은 난이도 벽(25·50번에서 ×1.39)과 **정확히 같은 자리**다.

> 벽 = 보상 해금 지점. 벽을 넘으면 새 콘텐츠가 열린다.
> 턱이 있으니 "넘자"가 되고, 넘으면 실제로 뭔가 열린다.

그리고 **25-50에서 보상 테이블이 끝난다.** 399챕터 중 25챕터, 전체의 6%.
그 뒤 374챕터는 같은 보상이 수치만 커진다.
공략의 결론이 "21-25까지는 무리해서라도 빨리 올라가라"인 이유가 이것이다.

## 2. 갖고만 있어도 세지는 것들 (보유 효과)

| 요소 | 방식 | 규모 |
|---|---|---|
| 코스튬 | **장착 안 해도** 보유 효과 | 총 27.5만 다이아 → 코어공격력 +210%, 골드 +30%, 경험치 +20% 등 |
| 유물 | 60레벨 MAX | 총 60만 다이아 → 공격력 +1500%, 생명력 +800%, 관통 +2000, 치확 +20%, 치뎀 +200%, 최종공격력 +100%, **몬스터 생명력 -30%** |
| 피규어 | 등급별 1개씩 보유 | **공격력 ×14.78, 생명력 ×6.13, 방어력 ×4** |

피규어 한 줄이 전부다. 모든 등급을 하나씩 "갖기만" 해도 공격력이 14배가 된다.
장착 슬롯 경쟁이 없으니 **수집 = 성장**이고, 뽑기를 돌릴 이유가 영구히 생긴다.

**세트 조건부 보유 효과**도 있다 — 무기 4슬롯이 전부 신화 이상이면
치명타·슈퍼치명타 확률 보유 효과가 켜진다. 그래서 "좋은 옵션"보다
"일단 신화 4줄 채우기"가 먼저다.

## 3. 끝이 보이는 육성 라인

유물은 60레벨 MAX에 도달하면 **뽑기 풀에서 빠진다.** 전부 MAX면 뽑기 자체가 막힌다.
→ 무한 뽑기가 아니라 "언젠가 끝난다"가 눈에 보인다.

## 4. 아꼈다 쓰는 자원 — 공략이 존재하는 이유

| 자원 | 지금 쓰면 | 아꼈다 쓰면 |
|---|---|---|
| 레이드 티켓 | 1단계: 신화 피규어까지 | 20-50의 2단계: **갓 피규어** |
| 펫 소탕권 | 지금 클리어한 등급까지만 | 터틀(전설 1번) 클리어 후: 전설 조각 |
| PvP 입장권 | 낮은 등수 | 스펙 오른 뒤 몰아 쓰면 적은 표로 높은 승점 |
| 강화석 | 낮은 등급 무기에 낭비 | 20챕터까지 극심하게 부족 |
| 옵션석 | 갓4·3·2에 좋은 옵션 | 갓1 4슬롯 열린 뒤 한 번에 |

**"지금 쓰면 손해, 나중에 쓰면 이득"인 자원이 다섯 개 이상.**
이게 플레이어가 고민할 거리를 만들고, 공략이 읽힐 이유를 만든다.

## 5. 곱연산 3단 치명타

치명타 → 슈퍼치명타 → 하이퍼치명타. **전부 곱연산.**
그래서 슈치확 100%가 돼도 치뎀·슈치뎀·하치뎀을 다 올려야 한다.

골드 스탯 추천 순서: `치확 MAX → 슈치확 MAX → 치뎀 1000 → 슈치뎀 1000 → 공 10000`

## 6. 방치 보상이 두 갈래

| | 온라인(절전모드) | 오프라인 |
|---|---|---|
| 골드·경험치 | 기준 | **-30%** |
| 변동폭 | 크다(랜덤) | 작다(안정) |
| 상자·장신구·스킬북 | 거의 같음 | 거의 같음 |

클리어 18초 이상이면 둘이 비슷해진다. 그래서 **"클리어 타임이 늘어나도 위로 올라가라"**가 성립한다.

## 7. 우리 게임(v0.4)과의 대조

| 설계 요소 | Blade Idle | 우리 | 차이 |
|---|---|---|---|
| 해금 지점 | 13곳, 챕터 20/25/50에 집중 | 12곳 (무공 8 + 비경 4), 관문 1~100 | 개수는 비슷 |
| 해금과 난이도 벽 | **같은 자리** | 벽 자체가 없음 | **없음** |
| 난이도 곡선 | 톱니(증가율 체감 + 25마다 벽) | 매 관문 ×1.17 단조 | **없음** |
| 보유 효과 | 코스튬·유물·피규어 | 장착만, 보유 개념 없음 | **없음** |
| 끝이 보이는 라인 | 유물 60 MAX면 풀에서 제외 | 없음 | **없음** |
| 아꼈다 쓰는 자원 | 5종 이상 | 없음 | **없음** |
| 치명타 체인 | 3단 곱연산 | 2단(치명/치명피해) | 1단 적음 |
| 방치 보상 | 온/오프 2갈래 | 1갈래 | — |
| 보상 테이블 끝 | 25챕터(전체 6%) | 관문 100 이후 신규 없음 | 비슷 |

**우리에게 진짜 없는 것은 네 가지다.**
① 난이도 벽 ② 벽과 해금의 일치 ③ 보유 효과 ④ 아꼈다 쓰는 자원

나머지(해금 개수, 보상 테이블이 끝나는 비율)는 이미 비슷하다.

## 8. 적용 (2026-10-17, v0.5)

### ① 난이도를 톱니로

```js
WALL_CYCLE = 10          // 10관문이 한 주기 — 지역이 바뀌는 자리와 같다
WALL_SHARE = 0.4         // 벽이 주기 성장의 40%를 혼자 먹는다(로그 기준)
DECAY = 0.64             // 주기 안에서 증가율이 이만큼까지 떨어진다
```

결과:

| 관문 | 이번 관문 배수 | 예전 공식 대비 |
|---|---|---|
| 2 | ×1.130 | 0.966 |
| 5 | ×1.110 | 0.840 |
| 9 | ×1.085 | **0.643** (벽 직전이 제일 수월하다) |
| **10** | **×1.874** | 1.030 ← 벽 |
| 11 | ×1.136 | **1.0000** (예전과 정확히 일치) |

**주기 전체 배수를 예전 ×1.17^10과 똑같이 맞췄다.** 그래서 10관문 경계마다
예전 곡선과 다시 만난다. 총량은 하나도 안 변하고 모양만 톱니가 됐다.

적 공격력도 같은 모양이고 HP보다 조금 더 가파르다(1.19 vs 1.17). 보상은 톱니로 만들지
않았다 — 벽에서 보상까지 튀면 벽 앞에 주차하는 게 이득이 되어버린다.

### ② 해금을 전부 벽 자리로

| 관문 | 열리는 것 |
|---|---|
| 10 | 무공 〈혈마해방〉 |
| 20 | 비경 〈흑도 전장〉 |
| 30 | 무공 〈운기조식〉 |
| 40 | 비경 〈한철 광산〉 |
| 50 | 무공 〈뇌정검〉 |
| 60 | 비경 〈영수 계곡〉 |
| 70 | 무공 〈질풍보〉 |
| 80 | 비경 〈고수의 동부〉 |
| 90 | 무공 〈천금수〉 |
| 100 | 무공 〈빙백신장〉 |
| 110 | 무공 〈만검귀종〉 |

**11개 벽에 빈자리가 없다.** 비경 난이도는 예전 기준(`base`)을 그대로 쓴다 —
개방 관문만 옮기고 난이도까지 밀면 보상이 뒤집힌다.

### ③ 화면에 벽을 보여준다

벽이 안 보이면 그냥 난이도 스파이크다. 세 가지를 넣었다.

- 상단에 `30관문까지 10 — 무공 〈운기조식〉` (다음 해금까지 남은 관문)
- 벽 관문에서는 지역 줄 앞에 `관문지기` + 붉은색
- `stageJump(s)`로 이번 관문이 몇 배 세졌는지 꺼내 쓸 수 있게 해뒀다

검증: `node tests/sim.mjs` 12시간 310~316관문 (적용 전 313).
초반은 0.25시간에 59관문으로 빨라졌다(적용 전 47) — 벽 직전이 수월해진 효과다.

## 9. 적용 ③ 보유 효과 — 병기보 (2026-10-17, v0.6)

### 있던 구멍

보유 효과(`EQUIP_TYPES.own`)는 이미 있었다. 문제는 **지금 가진 개수** 기준이었다는 것이다.

```js
arr.forEach((c, g) => { if (c > 0) m += def.own[g]; });   // 옛 코드
```

같은 등급 4개를 합치면 그 등급 개수가 0이 되어 **보유 효과가 통째로 날아간다.**
신품(`own` 2.0)을 전부 합쳐 천품을 만들면 공격력 배율에서 200%p를 잃는다.
"모두 합성" 버튼이 손해일 수 있었다.

영수·신물은 레벨 기준이라 영구였는데, 장비만 이랬다.

### 고친 방식 — 병기보

`s.codex[type][grade]`에 **한 번이라도 손에 쥐었는지**를 적는다. 지워지지 않는다.

- 뽑기에서 나오면 적는다 (`gacha` → `noteCodex`, 첫 획득이면 `first: true`)
- 합성으로 올라가도 적는다 (`merge` → `noteCodex(type, grade + 1)`)
- 보유 효과는 **개수가 아니라 병기보** 기준으로 계산

검증: 범품 4개 보유 → 배율 1.250 → 합성 후 1.670. **합성이 항상 이득이 됐다.**

기존 세이브는 지금 가진 최고 등급까지 전부 기록된 것으로 본다.
합성으로 올라간 것이므로 실제로 거쳐온 게 맞다.

### 도감 완성 효과

```js
CODEX_PER_TYPE = { crit: 0.05 }    // 한 부위 완성마다 치명타 확률 +5%p
CODEX_ALL      = { critDmg: 0.5 }  // 세 부위 모두 완성하면 치명타 피해 +50%p
```

근거: Blade Idle은 무기 4슬롯이 전부 신화 이상이면 치명타 보유효과가 켜진다.
"좋은 옵션 하나"보다 **"빈칸 없이 채우기"**가 먼저가 되는 장치다.

검증: 전부 미기록 → 치명 5.0% / 치명피해 1.50배,
세 부위 완성 → **치명 20.0% / 치명피해 2.00배**.

### 화면

- 부위 제목에 `병기보 5/6`, 완성하면 금색
- 지금 없지만 기록된 등급은 **점선 테두리 + "기록"**
- 보너스 줄이 `보유 +305%` → `병기보 +322%` (46관문 표본 기준, 공격력 ×15.9 → ×16.1)

검증: `node tests/sim.mjs` 12시간 302관문.
