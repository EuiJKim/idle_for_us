## 2. 온보딩 — 처음 4챕터만 손으로 다듬었다

| 챕터 | 웨이브 | 제한시간 |
|---|---|---|
| 1 | **1개** (38스테이지) | 25초 |
| 2 | 2개 | 30초 |
| 3 | 3개 | 40초 |
| 4 이후 **399챕터까지** | **4개 고정** | **47초 고정** |

챕터 1은 더 잘게 쪼개져 있다 — 1~24스테이지가 1웨이브 25초, **25스테이지에서 3웨이브 45초**,
26~39가 다시 1웨이브, 40~49가 2웨이브 30초, 50이 3웨이브 40초.

→ **첫 챕터에서만 난이도를 손으로 조각하고, 그 뒤로는 한 숫자(4웨이브·47초)로 19,000개를 돌린다.**

## 3. 난이도 곡선은 직선이 아니라 톱니다 ★

챕터 5의 스테이지별 적 HP 증가율:

```
st2  ×1.0255     st20 ×1.0175     st40 ×1.0194
st3  ×1.0249     st21 ×1.0172     st45 ×1.0177
st4  ×1.0243     st22 ×1.0169     st49 ×1.0165
  …증가율이 계속 작아진다…        …또 작아진다…
st24 ×1.0163     st25 ×1.3868 ←벽  st50 ×1.3872 ←벽
```

**25스테이지마다 ×1.39 벽이 서고, 그 사이는 증가율이 2.5%→1.6%로 점점 완만해진다.**
플레이어 체감은 "점점 수월해진다 → 턱 막힌다 → 다시 수월해진다"의 반복이다.

ATK도 같은 모양이고 **HP보다 항상 조금 더 가파르다** (st2 기준 HP ×1.0255 vs ATK ×1.0371).

한 챕터(50스테이지) 전체로는 ×3.2~5.0. 챕터를 넘을 때는 ×1.01~1.03으로 **이음매가 없다**
(ch100→ch101은 ×1.0100). 벽은 챕터 경계가 아니라 **25·50번 스테이지**에 있다.

## 4. 우리 게임과의 차이

| | Blade Idle | 우리 (v0.4) |
|---|---|---|
| 적 HP 증가 | 스테이지당 **×1.016~1.026**, 25마다 ×1.39 | 관문당 **×1.17 고정** |
| 곡선 모양 | 톱니 (증가율 체감 + 주기적 벽) | 단조 지수 |
| 온보딩 | 4챕터에 걸쳐 1→4웨이브 | 8관문마다 적 +1 (최대 5) |
| 한 판 길이 | 47초 고정 | 목표 45초 (`TARGET_STAGE_SEC`) |
| 콘텐츠 | 22종 | 5종 (들판·비경·시련·결투·토벌) |

한 판 길이는 거의 같다. **다른 건 곡선 모양이다.**
우리는 매 관문 똑같이 1.17배라 "점점 수월해지는 구간"이 없다.

## 5. 동시 등장 몬스터 수 — 못 알아냄

`WaveGroupTable`의 컬럼명은 클라이언트에 있다:
`monsterid_{0}` / `monsterusecount_{0}` / `monsterspawnpositiongroupid` /
`monsterspawnradius` / `monsterspawnoffsetx` / `monsterspawnoffsetz` /
`monsterrespawncount` / `monsterrespawntime` / `bossid_{0}` / `bosscount_{0}`

하지만 **값은 서버에서 내려받는다.** 로컬 DB에는 `wavegroup` ID(`102501` 같은)만 있다.
클라이언트에 `mMaxMonsterCount`·`mMaxMonsterLimitTime` 필드가 있으므로 동시 등장 상한은
분명히 존재하지만, 숫자는 `libil2cpp.so` 안에 상수로 박혀 있어 문자열로는 안 나온다.

확정된 것: **적은 지정 지점 둘레 반경 안에 흩뿌려지고(`monsterspawnradius`),
웨이브는 시간마다 다시 찬다(`monsterrespawncount`/`monsterrespawntime`).**

## 6. 적용 후보

1. 적 HP·ATK 공식을 **단조 지수 → 증가율 체감 + 주기적 벽**으로 (10관문마다 벽)
2. 초반 온보딩을 웨이브 수로 조절 (지금은 적 수로만 조절)
3. ATK 증가율을 HP보다 항상 조금 높게 유지 (이미 적용돼 있음: 1.19 vs 1.17)
