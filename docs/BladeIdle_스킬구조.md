# Blade Idle 스킬 구조 분석 (2026-10-18)

> 수치는 못 가져온다. 스킬 이름·설명·배율은 전부 서버에 있다.
> 로컬라이제이션 번들 345개를 꺼내봤더니 전부 2.6KB짜리 빈 껍데기였다 —
> 번역 문자열도 런타임에 서버에서 받는다.
> 대신 **동작 방식(아키타입)과 시스템 구조**는 클라이언트에 그대로 남아 있다.

## 1. 스킬이 '움직인다'

`SkillTable` 컬럼 (global-metadata.dat에서 추출):

```
skillID  skillgroupid  skilleffectid  skillbookid  skillexp
skillmovespeed                  ← 스킬이 날아가는 속도
skillmovetime                   ← 얼마나 오래 날아가는가
skillmovestopintervaldistance   ← 가다가 멈추는 간격
skillslottableid  skilltranscendence  skilltranscendenceid
```

클라이언트 코드에 있는 처리기:

```
SkillShootProjectile        발사체를 쏜다
SkillMoveStraightHandler    직선으로 간다
SkillChainTrace             적에서 적으로 옮겨탄다
SkillChainTraceProjectile   옮겨타는 발사체
SkillCreateEffOn            그 자리에 효과를 깐다
SkillMove
```

→ 스킬에 **속도·지속시간·정지간격**이 있다는 건, 즉발이 아니라 **날아가고 번지는** 것이 기본이라는 뜻이다.

## 3. 시스템 구조

| 요소 | Blade Idle | 우리 (v0.7) |
|---|---|---|
| 액티브/패시브 | `SkillGet_Active` / `SkillGet_Passive` 구분 | 액티브만 |
| 스킬 초월 | `SkillTranscendenceTable`, `ActiveSkillTranscendence` | 없음 |
| 슬롯 | `SkillSlotTable` — 슬롯 자체가 테이블(성장) | 4→6칸 (180·260관문) |

## 4. 우리 스킬의 문제

8개 전부가 **"즉발 + 범위"** 하나의 동작이다.

| 무공 | 종류 | 동작 |
|---|---|---|
| 선풍검 | 광역 | 즉발, 반경 150 |
| 뇌정검 | 광역 | 즉발, 반경 210 |
| 만검귀종 | 광역 | 즉발, 반경 300 |
| 빙백신장 | 단일 | 즉발 + 빙결 |
| 혈마해방 / 질풍보 / 천금수 | 버프 | 수치만 |
| 운기조식 | 회복 | 수치만 |

반경 숫자만 다르다. **80마리가 몰려오는 들판에서 셋을 구분할 이유가 없다.**

## 5. 가져올 수 있는 것

수치는 못 가져오지만 **동작은 전부 만들 수 있다.** 탑다운 평면이라 전부 성립한다.

| 아키타입 | 우리 식 이름(안) | 동작 | 80마리 들판에서의 쓰임 |
|---|---|---|---|
| ChainLighting | 연환벽력 | 가장 가까운 적부터 N명에게 옮겨탄다 | 흩어진 적 정리 |
| Dash | 발도돌격 | 무인이 직선으로 관통하며 벤다 | 뭉친 줄을 가른다 |
| TeleportSlash | 축지참 | 가장 먼 적/두목에게 순간이동 후 일격 | 두목 특화 |
| Field (지속) | 매화검진 | 그 자리에 N초간 남아 들어온 적을 벤다 | 길목 막기 |
| Tornado | 선풍장 | 장판이 스스로 굴러다닌다 | 방치형에 어울림 |
| Projectile 관통 | 일자검기 | 직선상의 적 전부 | 줄 세워진 적 |


## 6. 적용 (2026-10-18, v0.8)

무공 8종 → **14종**. 추가된 6종은 전부 **동작이 다르다**.

| 관문 | 무공 | motion | 동작 | 검증(적 80마리 기준) |
|---|---|---|---|---|
| 120 | 연환벽력 | `chain` | 가까운 적부터 옮겨탄다(12%씩 감쇠) | 11연쇄 |
| 130 | 발도돌격 | `dash` | 300만큼 파고들며 길 위를 벤다 | 무인 300 이동, 5타 |
| 140 | 축지참 | `blink` | 가장 먼 적(두목 우선)에게 순간이동 | 365 순간이동, 두목 2.2배 |
| 150 | 매화검진 | `field` | 그 자리에 6초간 남아 0.5초마다 | 572타 |
| 160 | 선풍장 | `tornado` | 회오리가 8초간 돌아다닌다 | 270타 |
| 170 | 일자검기 | `pierce` | 바라보는 방향 520 직선상 전부 | 5타 |

구현: `game.js`에 `hitCircle` / `hitBeam` / `damageMob` 세 개를 깔고
`castChain` / `castDash` / `castBlink` / `castField`, 그리고 `updateFields`로
바닥에 남는 것을 굴린다. 거리는 전부 화면 기준(`FIELD_SQUASH` 적용)이다.

자리를 옮기거나 들판에 남는 무공(`dash`/`blink`/`tornado`)은 1:1 겨루기에서는 막았다.

해금은 전부 벽 자리(120~170)다.

## 7. 칸이 늘어난다 (2026-10-20)

무공은 14종인데 칸이 넷이라 **열 개를 못 썼다.** 총 연마 보너스로 "안 쓰는
무공도 올릴 이유"는 만들었지만, 쓸 자리는 안 만들어 둔 셈이었다.

- 기본 **4칸**, `SKILL_SLOT_AT = [180, 260]`에서 한 칸씩 → 최대 **6칸**
- 둘 다 벽 자리다 (새로 열리는 것은 전부 벽에서 열린다는 규칙)
- 무공 탭 제목에 "지금 몇 칸 · 다음 칸은 몇 관문"을 띄운다
- `setSkillSlot`은 열린 칸만 받고, 출진 준비 불러오기도 열린 만큼만 채운다

## 8. 상태이상 넷 (2026-10-20)

동작은 여섯으로 갈라놨는데 **효과가 전부 피해**였다. 무공을 고르는 이유가
수치밖에 없었다. `CrowdControlTable`을 보고 넷으로 갈랐다.

| 상태이상 | 효과 | 붙은 무공 |
|---|---|---|
| 빙결 | 멈춤 | 빙백신장 3초 |
| 둔화 | 걸음 ×0.45 | 뇌정검 5초 · 연환벽력 4초 · 선풍장 3초 |
| 출혈 | 초당 그 일격의 22% | 선풍검 4초 · 발도돌격 6초 · 일자검기 5초 |
| 파쇄 | 받는 피해 ×1.35 | 만검귀종 8초 · 매화검진 4초 |

구현: `useSkill`이 `this.ccNow`에 그 무공의 상태이상을 올려두고, 피해를 주는
모든 경로(`hitCircle` / `hitBeam` / `dealAoe` / 연쇄 / 순간이동 / 장판)가
맞은 적마다 `applyCC`를 부른다. `tickCC`가 매 틱 시간을 깎고 출혈 피해를 넣는다.

- 같은 것이 겹치면 **더 긴 쪽이 남는다**. 출혈만 예외로 **더 아픈 쪽으로 갈아끼운다**
- 장판(매화검진·선풍장)은 장판이 때릴 때마다 다시 건다 — `updateFields`에서
  `f.cc`를 `ccNow`로 되돌려 깔아준다
- 파쇄는 `damageMob` 입구에서 곱해지므로 **모든 출처의 피해**에 적용된다

> **검증에서 헤맨 것**: 첫 시험이 "0마리에 둔화"였다. 코드 문제가 아니라
> 시험용 무인이 세서 **범위 안 적이 전부 죽은 것**이었다. 적 53 → 25로 줄었으니
> 상태이상이 남을 적이 없다. 약한 무인으로 다시 돌리니 둔화 27 · 출혈 12 ·
> 파쇄 47이 걸렸다. `tests/check.mjs` 섹션 7도 일부러 약한 무인을 쓴다.

## 9. 한자 제거 (2026-10-19)

화면에서 한자를 전부 뺐다. 107줄 65종 → **0**.

- 화폐 기호 銀寶秘鐵草片 → 은/원 + 본문은 "은자 1,234"
- 아이콘 1글자(拳氣穴破快 등) → 한글 2글자(외공·내공·혈도·파괴·쾌검)
- 무공 `hz` 필드 삭제 — 시전 배너에 한자 대신 무공 이름이 뜬다
- 탭의 한자 글리프 제거, 한글 라벨만
- 이름 속 괄호 한자 제거 (영원(靈猿) → 영원, 천마(天魔) → 천마)
- 상단 버튼 令設 → 📜⚙️
- 폰트 미리받기 글리프 목록도 한글로 교체

`tools/icon.html`(앱 아이콘 생성기)도 바꿨지만, **이미 만들어진 PNG 아이콘은
그대로다.** 아이콘까지 바꾸려면 그 도구로 다시 뽑아야 한다.
