# 보스전 구상 (v531 초안 · v532 제안 A 장 두목 · v535 제안 B 월드보스 실제 싸움 — 피하기는 지금 자동, 나중에 수동만)

## 지금 있는 것
- **칸 두목**: 칸마다 20마리 잡으면 「두목 도전」. 몹을 키운 두목 하나(체력 ×0.5) · 60초. 패턴은 사냥터 두목과 같은 예고 범위(붉은 범위 → 터짐) 몇 가지(`BOSS_PATS`).
- **사냥터 두목**: 300마리마다 들판에 나온다. 같은 패턴.
- **월드보스**: 90초 동안 넣은 피해 = 점수(화면 없이 계산만). 하루 3번.
- **전직 던전 · 병장고**(v531부터 실제 던전): 두목 하나를 정해진 시간 안에.

모두 「큰 몹 하나를 때린다」에 가깝다 — 두목마다 다르게 싸우는 맛 · 이겼을 때의 큰 한 방이 없다.

## 목표
1. 두목마다 **얼굴**이 있다 — 이름 · 칭호 · 등장 컷 · 고유 패턴 2~3개.
2. 싸움에 **고비**가 있다 — 체력이 줄면 국면이 바뀐다(분노 · 패턴 추가 · 졸개 부름).
3. 내가 **잘하면 줄어든다** — 피하기(수동) · 무력화(그로기)로 시간을 줄인다. 자동으로도 깰 수는 있다(방치형).
4. 이기면 **크게 터진다** — 마지막 일격 느린 화면 · 보상 상자 · 첫 처치 보상 · 도감.

## 제안 A — 장 두목(10칸마다 · 15명)  ★ 먼저 하기 좋음
- 10칸째 두목만 「장 두목」으로: 전용 맵(좁은 무대 · 발판 1층) · 체력 막대 여러 줄(×3 줄이 깎일 때마다 번쩍).
- **국면 3단**: 100~70% 기본 패턴 / 70~30% 분노(빨라짐 · 패턴 하나 추가) / 30% 아래 필살(화면 전체 예고 → 안전 지대로 피하기 · 자동은 피해를 크게 받음).
- **무력화 게이지**: 무공을 맞힐 때마다 차고, 가득 차면 5초 기절 + 받는 피해 ×2 — 무공 강화 · 트리가 보스전에서 빛나게.
- **패턴 틀 4가지**(두목마다 둘~셋을 고름 · 장마다 색 · 모양): 돌진(선) · 내려찍기(원) · 탄막(부채꼴 투사체) · 졸개 부르기.
- **연출**: 등장 컷인(이름 · 칭호 · 1.2초) · 국면 바뀔 때 화면 흔들림 + 대사 한 줄 · 마지막 일격 느린 화면(0.6초) · 「BOSS DEFEATED」.
- **보상**: 첫 처치 — 그 장 확정 장비 상자(정품上 이상) + 칭호. 다시 깨면 강화석 · 뽑기권.
- 기존 칸 두목(나머지 9칸)은 지금처럼 가볍게.

## 제안 B — 월드보스를 실제 싸움으로
- 지금은 계산만 → 실제 무대에서 90초. 거대 두목(화면 반을 차지) · 부위(머리 · 팔)마다 피해 배수.
- 30초마다 국면(방어 자세 → 약점 노출) — 약점 시간에 무공을 모아 쓰면 점수가 크게.
- 끝나면 순위 · 구간 보상(지금 점수표 그대로).

## 제안 C — 주간 토벌(문파 · 나중에)
- 한 주에 한 번 큰 두목 — 문파원 피해가 모여 체력을 깎는다(서버 필요). 문파가 붙을 때.

## 정해 주실 것
1. 어디부터: **A 장 두목**(권장) · B 월드보스 · 둘 다.
2. 필살(화면 전체 예고)을 **자동 사냥도 피하게** 할지(편함), **수동만 피할 수 있게** 할지(손맛 — 자동은 피해를 크게 받음).
3. 장 두목 15명의 얼굴(그림) — 지금 몹 그림을 키워 쓸지, 새로 그릴지(그림 도구로 15장).
