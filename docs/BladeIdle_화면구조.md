# Blade Idle 화면·전투 구조 분석 (2026-10-17)

> 1차 분석([BladeIdle_분석.md](BladeIdle_분석.md))은 SQLite 밸런스 테이블만 봤다.
> 이번엔 `base_assets.apk`(1.27GB)의 **Texture2D·GameObject 계층**을 UnityPy로 직접 읽었다.
> 추출 대상: 13,370개 Unity 데이터 파일 / Sprite 84,434 · Texture2D 2,713 · Canvas 392.

## 1. 결론부터 — 우리 게임이 틀린 지점

| | Blade Idle | 우리 게임(v0.3) |
|---|---|---|
| 시점 | **탑다운(바로 위에서)** | 옆에서 본 측면 |
| 이동 축 | **X·Z 2축 평면** | X 1축 |
| 적 배치 | 평면 사방 | 좌우 일직선 |
| 광역기 | **바닥 원형 장판** | 가로 범위 |

측면 1축으로 만든 게 원인. "자유롭게 움직인다"가 코드상 X축 하나뿐이었다.

## 2. 카메라 (근거: `assets/bin/Data/880d6909…`, GameModeProperty 계층)

```
CameraController   pos(0, 7, 0)    euler(90, 0, 0)   ← X축 90도 = 수직 하향
  CorrectionAxis   pos(0, 0, -50)                    ← 회전 후 실제로는 위쪽 50
    Camera         orthographic = True
                   orthographic_size = 5.0
                   near 0 / far 100
```

- **직교 투영**(원근 없음). 세로 10유닛, 가로 10×(720/1280)=**5.625유닛**이 화면에 들어온다
- 즉 전투장은 **세로로 긴 5.6 × 10 평면**. 캐릭터는 그 안을 돌아다닌다

## 3. 배경 (BG_Stage01~60, 전부 2048×2048)

- 60장 전부 **바로 위에서 내려다본 바닥 텍스처**. 측면 배경이 아니다
- 가운데 원형 문양 = 캐릭터 기본 위치 마커
- 정사각 2048 → 화면(세로 긴 비율)보다 넓다. 카메라가 그 위를 따라다니는 구조

## 5. 몬스터 체력바 (근거: `BattleUISystem_MainStage`)

- 상단 고정 바가 아니라 **몬스터 머리 위 개별 바 180×10**
- `TransformHPBar`라는 월드 추적 Canvas 아래에 붙는다
- 보스는 `BossHPBar` 별도, 버프 아이콘 15×15가 바 아래 3칸

## 6. 이펙트 (259장 추출)

전부 **흑백 원형 마스크**를 파티클 색으로 물들이는 방식:

- `TX_Circle_Line_01~15` — 링·호가 퍼지는 테두리
- `TX_Circle_Slash01~02` — 베는 호(초승달)
- `TX_Circle_Glow_*`, `TX_Circle_Aura01~02` — 발밑 글로우·회오리
- `FX_Shader_SkillArea_01` — **광역기 바닥 장판**
- `TX_Circle_Line_04` — 방사형 임팩트 버스트

탑다운이라서 원이 그대로 "범위"로 읽힌다. 측면 뷰에선 쓸 수 없는 문법이다.

## 7. 캐릭터·몬스터 아트

- `main_character` 512/1024/2048 3종, 몬스터 60종 이상(Swamp_, Darkknight_, dokkaebi_, Temple_Boss_, Boss_ …)
- 전부 **본 애니메이션용 부위 분리 아틀라스** — 머리·팔·다리·무기가 따로. 프레임 스프라이트시트가 아니다
- 따라서 그대로 가져다 쓸 수 없고, 구조(부위 분리 + 회전 조합)만 참고 대상

## 8. 저작권

추출물은 Mobirix 자산이다. **구조·배치·연출 문법 참고용**이고, 이미지 파일 자체를 우리 게임에 넣어 배포하면 안 된다. 그림은 우리가 따로 만들거나 라이선스 받은 것을 쓴다.

## 9. 적용 과제

1. 월드를 X 1축 → **X·Y 2축 평면**으로 (탑다운)
2. 적 스폰을 좌우 → **평면 사방**, 화면 밖 가장자리에서 걸어 들어오게
3. 카메라를 캐릭터 추적 + 직교, 가시영역 비율 5.6:10 유지
4. 광역기를 가로범위 → **바닥 원형 장판**(반지름 표시)
5. HUD를 탭바 → **좌우 세로 아이콘 줄 + 가운데 스킬 슬롯**
6. 몬스터 체력바를 머리 위 개별 바로
