# 回歸 우리끼리 회귀무림

친구 5명이서 같이 하는 무협 회귀 방치형 RPG. 수묵화풍 그림은 모두 코드로 직접 그린다(외부 그림 없음). 웹앱(PWA)이라 **안드로이드와 아이폰 모두** 홈 화면에 추가해서 앱처럼 쓸 수 있다.

**▶ 플레이: https://euijkim.github.io/idle_for_us/**

## 폰에 설치하기

- **아이폰:** 사파리로 링크 열기 → 아래 공유 버튼 → **홈 화면에 추가**
- **안드로이드:** 크롬으로 링크 열기 → 오른쪽 위 ⋮ → **홈 화면에 추가** (또는 **앱 설치**)

홈 화면 아이콘으로 열면 주소창 없이 전체화면으로 열리고, 새 버전은 다시 열 때 자동으로 반영된다.

## 게임 구성

| 탭 | 내용 |
|---|---|
| 修 수련 | **수련**(은자로 외공·내공·혈도·파괴력·쾌검·상재) · **레벨**(레벨업마다 스탯 포인트 2개 → 근력/체질/살기/투지/재운/오성) · **경지**(삼류 → 천인합일 10단계, 레벨을 채우고 심마(心魔)를 베면 공격력·체력 ×1.5, 기운·비검·광배로 외형 변화) · **회귀**(80관문 이후, 처음으로 돌아가는 대신 전생의 기억 → 모든 능력 영구 증가) |
| 兵 병기 | 검·호신의·옥패 뽑기(범품~천품), 같은 등급 4개 합성, 한철로 제련 |
| 武 무공 | 8초식(선풍검·혈마해방·운기조식·뇌정검·질풍보·천금수·빙백신장·만검귀종) 중 4개 장착, 비급으로 연마, 자동 시전 |
| 靈 영수 | **영수** 8종(알 부화, 영초로 성장, 함께 싸우는 영수 1마리 + 보유 효과) · **신물** 8종(만년한철·천년설삼·공청석유 등, 조각으로 발굴) |
| 洞 비경 | 흑도 전장(은자)·한철 광산(한철)·영수 계곡(영초)·고수의 동부(신물 조각). 하루 2번, 깨면 다음 단계, 깬 단계는 소탕 |
| 盟 무림 | **서열**(전투력 순위·캐릭터 구경) · **비무대**(친구 캐릭터와 자동 비무, 점수 순위, 하루 5번) · **문파**(코드 가입·출석·기부·버프·채팅·매일 혈마 토벌) |
| 令 의뢰 | 일일 의뢰 7개 + 모두 완료 보너스, 25관문마다 업적 |

강호 8지역(객잔 마을 → 죽림 → 황사 서역 → 천산 설원 → 혈사곡 → 귀곡 → 무당 운해 → 십만대산 마교)마다 배경과 적 무인(왈패·자객·강시·혈교·마교…)과 두목이 다르다.
자동 전투: 관문마다 적 10명 → 두목(30초 제한). 지면 그 관문에서 수련하다가 "두목 도전".
방치 보상: 앱을 꺼 둔 동안 은자와 경험치가 쌓인다(최대 12시간).

## 처음 한 번만: Firebase 설정

프로젝트 `idle-69772` ([Firebase 콘솔](https://console.firebase.google.com/project/idle-69772))

1. **Authentication → 로그인 방법 → 익명** 사용 설정
2. **Firestore Database → 데이터베이스 만들기** (위치 `asia-northeast3` 서울, 프로덕션 모드)
3. **Firestore Database → 규칙** 탭에 [`firestore.rules`](firestore.rules) 내용을 그대로 붙여넣고 **게시**

규칙을 게시하지 않으면 랭킹·길드·레이드가 "권한 없음"으로 실패한다. 혼자 하기는 Firebase 없이도 된다.

## 처음 한 번만: GitHub Pages

저장소 **Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main` / `(root)`** → Save.
1~2분 뒤 위 플레이 주소가 열린다.

## 개발

빌드 과정 없는 순수 HTML/JS(ES 모듈)다.

```bash
npx http-server -p 8123 -s -c-1 .     # http://localhost:8123
node tests/sim.mjs 24                  # 밸런스 시뮬레이션 (24시간 쉬지 않고 플레이 시 도달 스테이지)
```

```
js/data.js      수치·세계관 테이블 (경지, 무공, 지역별 적 외형, 회귀 …) (강화 비용, 몬스터 체력, 장비 효과 …) ← 밸런스는 여기만 고치면 된다
js/game.js      게임 규칙 (DOM 없음, Node에서도 동작)
js/battle.js    수묵화 전투 화면 (무인·배경·초식 이펙트를 모두 캔버스로 그림)
js/ui/*.js      하단 탭 화면 (성장·장비·스킬·동료·던전·친구, 미션)
                탭 안은 common.js의 subTabs()로 다시 나뉜다 — 아래 '창 구조' 참고
js/net.js       Firebase (익명 로그인, 프로필, 길드, 채팅, 레이드)
js/main.js      시작, 저장, 게임 루프, 방치 보상, 설정
sw.js           오프라인 캐시 (파일을 바꾸면 CACHE 이름을 올릴 것)
tools/gallery.html  모든 경지·적 무인을 한 장에 그려 보는 도감 (그림 확인용)
tools/icon.html     앱 아이콘 생성 페이지
```

### 창 구조

탭 하나에 카드를 세로로 쌓지 않는다. 모든 탭은 `subTabs()`로 다시 나뉜다.

| 탭 | 하위 탭 |
|---|---|
| 수련 | 수련 · 레벨 · 경지 · 문파 · 회귀 |
| 병기 | 병기 · 장신구 · 심검 |
| 무공 | 무공 · 패시브 |
| 영수 | 영수 · 신물 · 인물도감 · 의복 |
| 비경 | 수련터 · 광맥 · 탑 · 탐색 |
| 무림 | 서열 · 비무대 · 문파 · 그림자 · 창고 |
| 의뢰(모달) | 오늘 · 의뢰 · 업적 · 상점 |

**쓰는 자원은 창 머리에 띄운다.** 화면이 `res: ['books']`처럼 올리면
`main.js`의 `panelRes()`가 창 머리 자원칸을 그 자원으로 바꾼다.
올릴 수 있는 이름은 `js/ui/common.js`의 `RES_DEFS`에 있는 것뿐이고,
없는 이름을 올리면 조용히 사라지므로 `tests/wiring.mjs` 6절이 본다.

긴 목록은 **상태별로 묶는다** — 무공은 장착 중·쓸 수 있음·잠김,
영수는 데려간·가진·아직 없는 것으로 나뉜다.

### 브라우저 테스트 (Firebase 에뮬레이터)

```bash
npm i firebase-tools firebase@10.12.2           # 다른 폴더에서
firebase emulators:start --only auth,firestore --project idle-69772
FIREBASE_PKG=/path/to/node_modules/firebase node tests/e2e.cjs
```

혼자 하기(전투·강화·레벨·승급 시련·장비·스킬·펫·유물·던전·미션·방치 보상·저장)와 두 명이 같이 하는 흐름(길드·채팅·레이드·결투·랭킹·구경)을 확인한다. `?emu=1`을 붙이면 앱이 에뮬레이터에 연결된다.
